Button Action

About the Game

Looper is a 2D top-down puzzle game with time travelling mechanics for the Game Boy Advance that follows Adam on his quest to locate Elise, his fiance, after he gets fired from his job as a janitor under suspicious circumstances.

This is developed to be played on an emulator (or a Game Boy Advance if we manage to make a physical ROM), using a C++ engine/library called Butano for the core development and Python for Audio Backend.
